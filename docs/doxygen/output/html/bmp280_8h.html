◆ bmp280_init()

bool bmp280_init ( BMP280_HandleTypedef * dev,
bmp280_params_t * params )

Initialize BMP280/BME280 module.

Probes for the device, soft resets the device, reads the calibration constants, and configures the device using the supplied parameters.

The I2C address is assumed to have been initialized in the dev, and may be either BMP280_I2C_ADDRESS_0 or BMP280_I2C_ADDRESS_1. If the I2C address is unknown then try initializing each in turn.

This may be called again to soft reset the device and initialize it again.

Parametry
devDriver handle with I2C handle and address already set.
paramsSensor configuration parameters.
Zwraca
true on successful initialization.

◆ bmp280_read_fixed()

bool bmp280_read_fixed ( BMP280_HandleTypedef * dev,
int32_t * temperature,
uint32_t * pressure,
uint32_t * humidity )

Read compensated fixed-point temperature, pressure and optional humidity.

Temperature in degrees Celsius times 100.

Pressure in Pascals in fixed point 24 bit integer 8 bit fraction format.

Humidity is optional and only read for the BME280, in percent relative humidity as a fixed point 22 bit integer and 10 bit fraction format.

Parametry
devDriver handle.
temperature[out] Temperature in centi-degrees Celsius.
pressure[out] Pressure in Pa using 24.8 fixed-point format.
humidity[out] Optional humidity in BME280 fixed-point format.
Zwraca
true when data was read and compensated.
