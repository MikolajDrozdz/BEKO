BEKO Pager Firmware

Wprowadzenie

BEKO Pager Firmware to aplikacja STM32 dla bezprzewodowego noda systemu pagerowego. Kod aplikacyjny znajduje sie w Core/App i obejmuje:

  • warstwe radiowa SX1276/RFM95 z backendami LoRa, FSK i OOK,
  • protokol ramki LAVIET_FRAME_V1,
  • kryptografie AES-CTR oraz HMAC-SHA256,
  • zadanie security z TPM ST33KTPM2X i magazynem I2C EEPROM/FRAM,
  • lokalny interfejs LCD, menu, przyciski i LED,
  • sensory BMP280 oraz VL53L3CX,
  • opcjonalna konsole serwisowa UART.

Punkty startowe

Najwazniejsze pliki publicznego API:

  • Core/App/app.h - inicjalizacja aplikacji i wspolne wrappery I2C,
  • Core/App/radio_main.h - zadanie radiowe i komendy runtime,
  • Core/App/security_main.h - zadanie security, klucze i trusted storage,
  • Core/App/laviet_frame.h - parser i serializer ramki LAVIET,
  • Core/App/laviet_crypto.h - HMAC-SHA256, AES-CTR i porownanie MAC,
  • Core/App/menu_main.h oraz Core/App/lcd_main.h - lokalny UI.
