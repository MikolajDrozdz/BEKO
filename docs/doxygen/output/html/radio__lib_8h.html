Opis szczegółowy

Główne API biblioteki radiowej.

Ten plik udostępnia jednolite API dla aplikacji. Domyślny backend nadal może być wskazany kompilacyjnie przez radio_lib_config.h, ale warstwa aplikacji może go również przełączyć w runtime przez radio_select_backend(...).
