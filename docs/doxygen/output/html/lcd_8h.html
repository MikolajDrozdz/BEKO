Write one padded/truncated text line.

Parametry
rowZero-based row index.
textText to render.
widthMaximum display width.
Zwraca
true when the line was written.

Write one padded/truncated text line.

Writing the whole row every time avoids leftover characters when a shorter string replaces a longer one, which is especially visible in menu screens and popup overlays.
