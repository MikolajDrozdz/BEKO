Mapa modulow

Core application

  • app.h - inicjalizacja aplikacji, start RTOS i wrappery I2C.
  • pager_config.h - przelaczniki build/board.
  • service.h - opcjonalna konsola UART.

Radio

  • radio_main.h - wysokopoziomowe komendy: wysylanie, pairing, hopping, auto-ping i rekonfiguracja profili.
  • radio_lib/radio_lib.h - wspolna fasada na backendy modulacji.
  • radio_lib/modulations/lora/radio_lora.h - backend LoRa.
  • radio_lib/modulations/fsk/radio_fsk.h - backend FSK/GFSK/MSK/GMSK.
  • radio_lib/modulations/ook/radio_ook.h - backend OOK.
  • radio_lib/common/sx1276/radio_sx1276.h - niskopoziomowy dostep SPI do rejestrow SX1276.

Protocol and crypto

  • laviet_frame.h - struktura, walidacja, kodowanie i dekodowanie ramki.
  • laviet_crypto.h - HMAC-SHA256, AES-CTR, self-test i software fallback.

Security and storage

  • security_main.h - trusted devices, klucze, countery, TPM bootstrap.
  • st33ktpm2x_lib/st33ktpm2x.h - sterownik TPM2/TIS/FIFO przez I2C.
  • i2c_mem_store_lib/i2c_mem_store.h - EEPROM/FRAM log i encrypted secret slots.

User interface

  • menu_main.h - stan menu i notyfikacje z innych subsystemow.
  • lcd_main.h - kolejka renderowania ekranow.
  • lcd_library/lcd.h - driver LCD HD44780 po ekspanderze I2C.
  • button_main.h - polling i debounce przyciskow.
  • led_array_lib/led_array_lib.h - efekty i PWM LED.

Sensors

  • bmp280_lib/bmp280.h - niskopoziomowy driver BMP280/BME280.
  • bmp280_lib/bmp280_api.h - aplikacyjny wrapper single-shot.
  • vl53l3cx_lib/vl53l3cx_lib.h - aplikacyjny wrapper VL53L3CX.
