◆ lcd_main_show_menu()

bool lcd_main_show_menu ( const char * l0,
const char * l1,
const char * l2,
const char * l3 )

Replace the menu screen with four LCD lines.

Parametry
l0First line.
l1Second line.
l2Third line.
l3Fourth line.
Zwraca
true when the screen was queued.

Replace the menu screen with four LCD lines.

Menu navigation used to enqueue each line separately, which could leave stale rows on screen when the LCD queue was busy. Sending the whole frame atomically keeps the UI coherent.
