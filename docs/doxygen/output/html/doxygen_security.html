Bezpieczenstwo

LAVIET_FRAME_V1

Ramka LAVIET zawiera:

  • wersje i typ,
  • flagi,
  • identyfikatory zrodla i celu,
  • msg_id,
  • licznik anti-replay,
  • payload do 16 bajtow,
  • 32-bajtowy mac_tag.

Szczegoly API sa w laviet_frame.h.

Kryptografia

laviet_crypto udostepnia:

  • HMAC-SHA256 dla integralnosci i autentycznosci ramek,
  • AES-CTR dla szyfrowania payloadu bez paddingu,
  • staly czas porownania MAC przez laviet_mac_equal(),
  • bezpieczne czyszczenie buforow przez laviet_secure_zero().

Modul probuje uzyc sprzetowych blokow HASH/CRYP, ale zachowuje software fallback, gdy sprzetowy self-test nie przejdzie.

TPM

st33ktpm2x implementuje transport ST33KTPM2X przez I2C/TIS/FIFO i podstawowe komendy TPM2. security_main uzywa TPM jako punktu zaufania dla root seed, materialu kluczowego i operacji wymagajacych Physical Presence.

Storage

i2c_mem_store dzieli zewnetrzna pamiec I2C na:

  • ring log odebranych wiadomosci,
  • szyfrowane sloty sekretow/trusted devices.

Sekretne payloady sa chronione przez XTEA-CTR i CRC w warstwie storage.
