int32_t tof_get_distance ( void )

Read one distance sample in millimeters.

Nota
Funkcja jest blokujaca: czeka na swieza probke z czujnika. Czas blokowania zalezy od TimingBudget (aktualnie ~30 ms + narzut magistrali).
Zwraca
Distance in millimeters, or a negative value on failure.
