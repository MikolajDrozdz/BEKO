Generowanie dokumentacji

Wymagania

Do wygenerowania dokumentacji HTML potrzebny jest Doxygen. Do pliku PDF potrzebny jest tez LaTeX z pdflatex i makeindex.

Na Ubuntu zestaw narzedzi mozna zainstalowac komenda:

sudo apt-get install doxygen graphviz texlive-latex-base texlive-latex-extra texlive-fonts-recommended texlive-lang-polish

Komenda

Uruchom generator HTML i LaTeX z katalogu glownego repozytorium:

doxygen Doxyfile

Wynik HTML:

docs/doxygen/output/html/index.html

PDF powstaje z wygenerowanych plikow LaTeX:

make -C docs/doxygen/output/latex

Wynik PDF:

docs/doxygen/output/latex/refman.pdf

Zakres wejscia

Konfiguracja dokumentuje:

  • README.md,
  • Core/App,
  • docs/doxygen.

Katalogi Drivers, Middlewares, Debug, .git i .metadata sa wykluczone. Dzieki temu dokumentacja skupia sie na kodzie aplikacji BEKO, a nie na wygenerowanym lub zewnetrznym kodzie HAL/BSP/FreeRTOS.

Polityka plikow wynikowych

Wygenerowany HTML jest ignorowany przez Git przez wpis:

docs/doxygen/output/

W repo zostaja tylko zrodla dokumentacji i konfiguracja.
