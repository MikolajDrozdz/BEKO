\begin{DoxyItemize}
\item warstwe radiowa SX1276/\+RFM95 z backendami Lo\+Ra, FSK i OOK,
\item protokol ramki {\ttfamily LAVIET\+\_\+\+FRAME\+\_\+\+V1},
\item kryptografie AES-\/\+CTR oraz HMAC-\/\+SHA256,
\item zadanie security z TPM ST33\+KTPM2X i magazynem I2C EEPROM/\+FRAM,
\item lokalny interfejs LCD, menu, przyciski i LED,
\item sensory BMP280 oraz VL53\+L3\+CX,
\item opcjonalna konsole serwisowa UART.
