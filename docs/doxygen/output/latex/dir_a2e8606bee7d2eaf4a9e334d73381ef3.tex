\hypertarget{dir_a2e8606bee7d2eaf4a9e334d73381ef3_autotoc_md56}{}\doxysubsection{\texorpdfstring{radio\+\_\+lib}{radio\+\_\+lib}}\label{dir_a2e8606bee7d2eaf4a9e334d73381ef3_autotoc_md56}
Modułowa biblioteka radiowa dla układów SX1276/\+RFM95 (np. RFM95\+W-\/862\+S2) dla STM32. Warstwa aplikacyjna korzysta z jednego API ({\ttfamily \doxylink{radio__lib_8h}{radio\+\_\+lib.\+h}}), a backend może być wybierany zarówno kompilacyjnie, jak i przełączany w runtime.\hypertarget{dir_a2e8606bee7d2eaf4a9e334d73381ef3_autotoc_md57}{}\doxysubsection{\texorpdfstring{Cele projektu}{Cele projektu}}\label{dir_a2e8606bee7d2eaf4a9e334d73381ef3_autotoc_md57}

\begin{DoxyItemize}
\item Stabilne API do inicjalizacji, TX/\+RX i obsługi zdarzeń IRQ.
\item Rozdzielenie warstwy sprzętowej (rejestry SX1276) od logiki modulacji.
\item Możliwość rozbudowy o kolejne backendy bez zmian w aplikacji.
\item Utrzymanie zgodności z kodem generowanym przez Cube\+MX.
\end{DoxyItemize}\hypertarget{dir_a2e8606bee7d2eaf4a9e334d73381ef3_autotoc_md58}{}\doxysubsection{\texorpdfstring{Struktura katalogu}{Struktura katalogu}}\label{dir_a2e8606bee7d2eaf4a9e334d73381ef3_autotoc_md58}
