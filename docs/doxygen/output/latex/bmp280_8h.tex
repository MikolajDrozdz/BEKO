Initialize BMP280/\+BME280 module. 

Probes for the device, soft resets the device, reads the calibration constants, and configures the device using the supplied parameters.

The I2C address is assumed to have been initialized in the dev, and may be either BMP280\+\_\+\+I2\+C\+\_\+\+ADDRESS\+\_\+0 or BMP280\+\_\+\+I2\+C\+\_\+\+ADDRESS\+\_\+1. If the I2C address is unknown then try initializing each in turn.

This may be called again to soft reset the device and initialize it again.

\hline
\end{DoxyParams}
