\doxysubsection{Opis szczegółowy}
High-\/level and transport-\/level driver for ST33\+KTPM2X over I2C (TIS/\+FIFO). 

This module provides\+:
\begin{DoxyItemize}
\item low-\/level TPM TIS over I2C access,
\item locality handling,
\item command/response transport,
\item selected TPM2 helper commands for security feature development.
\end{DoxyItemize}

The implementation is designed to be extensible. For advanced commands (sessions, HMAC, policy, NV authorization), use raw command transport APIs and add dedicated marshaling helpers in your application layer.
