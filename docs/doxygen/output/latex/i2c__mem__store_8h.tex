\doxysubsection{Opis szczegółowy}
I2C NVM storage library for received messages and encrypted service codes. 

This library targets external I2C memory (EEPROM/\+FRAM family) connected to I2\+C1. It provides\+:
\begin{DoxyItemize}
\item append-\/only ring log for received radio messages,
\item dedicated encrypted partition for trusted-\/device/service codes.
\end{DoxyItemize}

Encryption uses XTEA-\/\+CTR software cipher with a 128-\/bit key from configuration. For production security, derive/load this key from TPM-\/protected material.
